# Image drop folder

Drop your photography here. The live checklist at `/styleguide/images` lists every exact
filename the site expects and whether it exists. Folders:

- `hero/` — rotating homepage hero slides (landscape, min 2400px wide)
- `destinations/<slug>/` — cover + gallery per full destination; cover only for "on request" ones
- `tours/<slug>/` — cover (+ optional gallery) per tour
- `team/` — portraits (4:5 portrait crop)
- `about/` — storytelling / about imagery
- `og/` — default social-share image (1200x630)

Until your images are added the site will show a neutral branded placeholder, never a broken image.
