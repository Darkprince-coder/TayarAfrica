# Image drop folder

Drop your photography here. The exact filenames and sizes will be listed at the end of
Phase 1 (once the demo content is final). Folders:

- `hero/` — rotating homepage hero slides (landscape, min 2400px wide)
- `destinations/<slug>/` — cover + gallery per destination
- `experiences/<slug>/` — cover + gallery per package
- `team/` — portraits (4:5 portrait crop)
- `about/` — storytelling / about imagery
- `og/` — default social-share image (1200x630)

Until your images are added the site will show a neutral branded placeholder, never a broken image.
